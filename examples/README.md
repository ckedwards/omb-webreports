# Examples

`reports/blue-jays-2026/` is a complete, real report, kept here as a reference
for structure, stat tiles, several chart forms, sortable tables behind tabs and
live updates. It isn't served and won't run as-is: it queries a bot database
named `bramble` (`batting_stats`, `pitching_stats`, `team_record` tables).

For every component and chart form on synthetic data that runs anywhere, see
the design gallery: `webroot/reports/_gallery/` (served at `SITE/reports/_gallery/`).
